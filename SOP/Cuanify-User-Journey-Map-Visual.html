Journey Map Presentation

Crumbella User Journey Per Fase

Versi visual untuk presentasi tim produk, engineering, dan operasional. Fokus pada alur lintas persona dari onboarding hingga optimasi bisnis berbasis data.

Persona: Owner Persona: Cashier Persona: Bakery Ops Scope: POS + Booking + Analytics

1) Timeline Journey Utama

Fase A: Onboarding & Aktivasi

Setup akun, business profile, master data, dan readiness transaksi pertama.

Fase B: Operasi Harian POS

Open shift, transaksi, kontrol kas, dan sinkron stok real-time.

Fase C: Operasi Bakery Booking

Parse order, validasi jadwal/ongkir, automasi produksi, dan fulfillment.

Fase D: Monitoring & Optimasi

Analitik, insight AI, dan keputusan perbaikan margin serta efisiensi.

2) Journey Map Per Fase (Swimlane)

Fase Persona Goal Aktivitas Inti Touchpoint Sistem Pain / Risiko KPI Fase
A Owner Go-live secepat mungkin dengan data dasar yang benar. Register, buat bisnis, isi produk/kategori/ingredient, setup staff. Auth, onboarding, master data, role management. Setup tidak lengkap membuat analitik bias. Time to first transaction, data completeness.
B Cashier Proses transaksi cepat tanpa kehilangan akurasi. Open shift, input penjualan, close shift, rekonsiliasi kas. POS, cashier shift, debt, inventory deduction. Salah input saat jam ramai, mismatch kas akhir shift. Tx/sec kasir, shift discrepancy rate.
C Bakery Ops Order-to-fulfillment rapi, minim miskomunikasi produksi. Parse WA, validasi slot/libur/ongkir, create booking, update status. Booking form, shipping quote/resi, automations, calendar. Jadwal bentrok, notifikasi gagal, data alamat tidak valid. On-time fulfillment, automation delivery rate.
D Owner Ambil keputusan berbasis data, bukan intuisi semata. Pantau dashboard, review insight AI, eksekusi aksi korektif. Analytics, forecast, AI insights, exports. Insight tidak diterjemahkan jadi aksi operasional. Revenue growth, margin lift, waste reduction.

3) Momen Kritis per Persona

Owner

  • Hari 1: data master harus valid sebelum traffic transaksi naik.
  • Minggu 1: konsistensi tim input transaksi dan stok.
  • Minggu 2: keputusan pertama berbasis dashboard.

Cashier

  • Jam puncak: UI transaksi wajib tetap cepat dan jelas.
  • Tutup shift: expected cash vs actual cash harus transparan.
  • Edge case kasbon/split payment perlu guardrail kuat.

Bakery Ops

  • Validasi tanggal libur dan kapasitas sebelum order disimpan.
  • Rule pengiriman dan berat item harus konsisten.
  • Automasi WA/Calendar/Sheets harus bisa dipantau dan di-retry.
